# Pethinho Hotel

Sistema de agendamentos para hospedagem, creche e banho e tosa.

## Status

Em desenvolvimento. Não utilizar para reservas reais.

## Tecnologia

Next.js, TypeScript, Supabase PostgreSQL e autenticação com RLS.

## Segurança

Não adicionar chaves privadas ao repositório. Configurar variáveis de ambiente localmente.

## Infraestrutura

Supabase: projeto `pethinho-hotel-dev` (São Paulo).

## Próximos módulos

Portal do cliente, calendário, validação de disponibilidade, painel administrativo, check-in e check-out.
